Project guide

Problem framing, formulas, scope and how to run the app.

Problem statement

Social networks can be viewed as mathematical systems of users, relationships, rules and connections. This project demonstrates how a small network can be counted, tested, represented and analysed through Discrete Mathematics.

Objectives

  • Represent users as vertices and relationships as edges.
  • Calculate degree, centrality, density and possible edges.
  • Explore paths and connectivity.
  • Connect the model to all five syllabus units.

Assumptions & limitations

  • Six-user starter dataset is synthetic.
  • Relationships are undirected and unweighted.
  • Changes stay in the current browser session.
  • No server, authentication, database or live social-media connection.
  • Feature vectors are illustrative inputs.
For real research, use approved/consented data, protect privacy, and define each relationship before interpreting results.

  1. Open index.html in a modern browser or VS Code Live Server.

  3. Try formulas and shortest paths in Math lab.
